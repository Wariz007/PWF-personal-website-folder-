Personal Website
About

this website was created as platform for me to share my writings on how to solve problems in Nigeria and bring about prosperity.

the platform focuses on 3 key subjects:

entrepreneurship

book Reviews

and technology

visitors can filter the writings by subject using dedicated buttons, making navigation simple even as the content grows.

Features

subject filtering: quickly view writings by category.

dynamic content loading: writings are managed in a JSON file, so adding new content is easy without touching the code.

responsive design: optimized for different screen sizes and devices.

clean, intuitive UI: focus on readability and ease of navigation.

Tech Stack

the tech i used to create the platform is very simple, and i chose this tech stack specifically for they're simplicity and convenience to work together.

React for component-based development for modular and reusable code.

SASS for flexible and maintainable styling.

JSON to dynamically manage writings for quick updates.
